# Google Play policy source index

Use these official pages as starting points. Policy changes over time; open the current page before quoting exact requirements or advising a release decision.

- Target API level policy: https://support.google.com/googleplay/android-developer/answer/11926878
- New personal developer account testing requirements: https://support.google.com/googleplay/android-developer/answer/14151465
- Prepare app for review / App content declarations: https://support.google.com/googleplay/android-developer/answer/9859455
- User Data, privacy, disclosures, and account deletion: https://support.google.com/googleplay/android-developer/answer/10144311
- Data safety section: https://support.google.com/googleplay/android-developer/answer/10787469
- Payments policy: https://support.google.com/googleplay/android-developer/answer/9858738
- Sensitive permissions and location: https://support.google.com/googleplay/android-developer/answer/16558241
- Android developer verification and package registration: https://support.google.com/googleplay/android-developer/answer/16984799

For this skill's initial draft, official pages were checked on 21 November 2026. At that time, Google's target API page said new apps and updates must target API 36 or higher from 31 August 2026; the new-personal-account testing page specified 12 continuously opted-in closed testers for 14 days; and account creation triggered both in-app and external account-deletion paths. Verify all of these again at use time.
